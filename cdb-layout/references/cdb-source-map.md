## Distilled Rules

- Layout begins with reading path, not decoration.
- Proximity groups related information; distance separates unrelated information.
- Alignment creates order and makes scanning easier.
- Repetition creates system memory across repeated elements.
- Contrast should point to priority, not produce random visual noise.
- Density must match the task and medium.
