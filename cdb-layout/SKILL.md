# CDB Layout

Use this skill to organize information on posters, slides, UI screens, diagrams, and pages.

## Core Position

Layout is how information is arranged in a limited space. The reader should not have to guess what to read first or which elements belong together.

## Workflow

1. Define the reading path:
   - first glance
   - second glance
   - supporting details
   - final action or memory
2. Group related information.
3. Apply CRAP checks:
   - Contrast: what is most important?
   - Repetition: what pattern makes the system coherent?
   - Alignment: what invisible lines organize the page?
   - Proximity: what belongs together?
4. Adjust density: crowded, balanced, or too sparse.
5. Decide whether the issue is structural before adding decoration.
6. Provide a layout change plan that can be executed.

## Checks

- Do not move elements without defining reading order.
- Do not use color or effects to hide weak structure.
- Do not leave related items far apart or unrelated items too close.
- Do not center everything by default.
- Do not make every element equally prominent.
