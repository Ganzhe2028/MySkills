# Learner Contract

This file contains stable preferences. Current task progress belongs in Notion and must be re-read from the latest linked page.

## Interaction defaults

- Reply in Chinese; retain useful English task terms.
- Lead with the diagnosis or outcome, not the process used to reach it.
- Keep the final handoff short.
- When the next learning step is unambiguous, create the Notion page immediately.
- Ask for review only when the route changes, the workload materially expands, a paid resource is required, evidence is insufficient, or existing content could be affected.
- Do not ask routine “should I continue?” questions.

## Workload and friction

- Daily learning time must not exceed 60 minutes.
- Default worksheet length: 15–25 minutes.
- Instructions must be specific enough that the learner can begin without deciding how to interpret or sequence them.
- Prefer one small completed worksheet over a large unfinished plan.
- Use direct links, explicit time boxes, stop rules, and acceptance criteria.

## Notion behavior

- Existing learning pages are process records. Preserve them.
- If a page contains learner answers, annotations, comments, or partial work, create a new sibling page by default.
- Edit an existing page only when the user explicitly asks for that page to change.
- Before any edit, fetch the current page again and apply the smallest targeted change.
- Empty input locations always use `【　　】`, with exactly two full-width spaces.
- Put the label and its only input location on the same line.
- Never use extra lines such as “在这里填写” or “在这里粘贴”.

## Known design corrections

These are permanent rules learned from previous failures:

- Do not replace a page after the learner has started writing in it.
- Do not separate a field label from a second generic “填写” line.
- Do not tell the learner an answer and then ask them to enter the same answer.
- Do not ask for recall of old answer letters when the intended skill is evidence judgment or transfer.
- Do not interpret an abandoned full mock as a valid score when the learner was still learning the format.
- Do not make the learner reconstruct the task from prose. The page must carry the material, steps, timing, and stopping condition.
- Treat “看不懂这句话” or “不像人说的话” as worksheet-friction evidence. Rewrite the instruction in ordinary spoken Chinese before diagnosing academic difficulty.
- Do not ask vague method-extraction questions. State the concrete action and the expected answer form so the learner is not forced to guess the worksheet writer's wording.
- Treat the learner's label for a struggle as experience evidence, then verify the actual bottleneck against the step-by-step work.
- Do not use generic reflection fields that cannot change the next diagnosis. A blank reflection field does not cancel evidence already present in answers, annotations, or self-corrections.
- When answers are checked after submission, tell the learner the exact order. Preserve the first response and place later corrections in a separate field or annotation.
