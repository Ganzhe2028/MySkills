# IELTS Academic Reading Adapter

Use this reference only for IELTS Academic Reading.

## Evidence to inspect

- answer choices and answer changes;
- selected or highlighted text;
- vocabulary marks;
- comments such as “每个词都认识但整句看不懂”;
- time used and stopping point;
- repeated scrolling or searching;
- questions about how to use the worksheet;
- whether a supplied sentence actually proves the selected answer.

The aim is to locate the broken decision, not merely count correct answers.

## Micro-skill map

### Format exposure

The learner is still discovering sections, question groups, answer formats, or navigation.

- Do not score the attempt as a valid mock.
- Teach one question type and one answer-entry rule.
- Use a diagnostic or micro-practice page.

### Task interpretation

The learner cannot tell whether the question asks for a paragraph, truth value, word, heading, or short answer.

- Restate the required output.
- Show one worked example.
- Use a different item for independent practice.

### Locating

The learner cannot find the relevant region.

- Identify distinctive meaning, not only repeated surface words.
- Practise a bounded scan of one or two paragraphs.
- Do not require a full passage reread.

### Evidence validation

The learner finds related vocabulary but the sentence does not answer the question.

- Ask: “If this sentence were the only evidence, would it fully answer the question?”
- Compare the question's requested relationship with the sentence's actual relationship.
- Practise on one false match and one valid match.

### Paraphrase mapping

The learner has the right evidence but cannot see the relationship.

- Map one question phrase to one source phrase.
- Require a short Chinese explanation of why they correspond.
- Do not ask for a long translation.

### Long-sentence skeleton

Words are mostly familiar but clauses are not integrated.

- Find actor, main action, result, and the noun modified by `that/who/which`.
- Split the sentence into semantic chunks.
- Reconnect the causal or referential chain.

### Purpose or application sentence

Background information distracts from a question asking about a possible use.

- Scan for structures such as `researchers/scientists/engineers + explore/develop/use`.
- Read the complete purpose sentence.
- Ignore background unless it is needed to identify the outcome.

### Timing and execution

Only train timing after the learner can perform the underlying decision without severe format or instruction friction.

- Start with one question group.
- Progress to a passage when the group process is stable.
- Attempt a full 60-minute reading test only after several successful groups and a passage can be completed near 25 minutes.

## Next-task rules

- Select one or two micro-skills from the learner's latest evidence.
- If the learner has just seen the answer, do not reuse the same item as a transfer test.
- Constructed practice material must be labelled as practice, not official IELTS material.
- Use official material links when the task depends on the authentic passage.
- A supplied evidence sentence and a requested paragraph letter are often redundant. Ask instead for the relationship that proves the answer, or use a new item.
- A closed-book step should retrieve the rule: for example, “题目问用途时先找哪类表达？” It should not ask for `Q2 = G`.

## Progression example

1. Format exposure: learn how Matching Information answers are entered.
2. Micro-practice: distinguish keyword overlap from valid evidence.
3. Micro-practice: map the question phrase to the evidence phrase.
4. Transfer: apply both decisions to a new short paragraph.
5. Reduced scaffold: complete a new question group.
6. Independent practice: complete one passage with a time target.

Advance based on observed transfer, not on calendar days.
