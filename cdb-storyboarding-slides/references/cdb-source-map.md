## Distilled Rules

- A slide is a timed information unit, not a document page.
- Storyboarding plans the viewer's attention before visual styling.
- Each transition must clarify a reveal, comparison, transformation, or movement.
- Large paragraphs on slides create attention conflict.
- Audience losing focus is a design problem to diagnose.
