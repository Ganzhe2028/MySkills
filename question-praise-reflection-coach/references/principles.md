# 提问式赞美反思原则

## Core formula

Use this pattern as the smallest unit:

`具体细节 -> 基于事实的克制正反馈 -> 一个能唤起回忆的问题`

The value is not the praise itself. The value is helping the user return to the scene and notice their own effective behavior, judgment, and change.

## What counts as evidence

Good evidence comes from the memo itself:

- a concrete action: "我先停了一下", "我把问题拆成两部分"
- a choice: "我没有继续争辩", "我决定主动说清楚"
- an expression: a sentence the user said or wrote
- a scene detail: who was present, what changed, what pressure existed
- an emotional movement: from anxious to calm, annoyed to curious, passive to active
- a judgment signal: timing, risk, priority, boundary, responsibility, or value

Do not praise traits without evidence. Prefer "你当时先复述对方担心的点，这说明你在尝试降低误解" over "你很会沟通".

## Question design

Good questions are small enough to answer and concrete enough to trigger memory:

- ask "那个瞬间你看到了什么、听到了什么" instead of "当时是什么情况"
- ask "你从哪个信号判断不能再拖" instead of "你为什么这么做"
- ask "这个情绪变化发生在哪个节点" instead of "你有什么感受"
- ask "如果把这次做法写成一句可复用原则，会怎么写" instead of "你学到了什么"

Every question should invite the user to keep authorship of their own story.

## Boundaries

- Avoid routine-sounding "high EQ" templates.
- Avoid turning praise into free consulting requests.
- Avoid dense questioning; five questions is the default maximum.
- Avoid advice when the user asked for reflection.
- Avoid consultant, therapist, teacher, or motivational-speaker tone.
- Keep the voice like a careful friend who genuinely read the memo.

## If the user asks for outward-facing praise

This skill can help only when the user explicitly asks to convert the reflection into wording for another person. In that case, keep the same constraints:

- use observed details
- ask one low-burden question
- avoid flattery and labels
- do not request a full method, lesson, or unpaid consultation unless the relationship supports it
