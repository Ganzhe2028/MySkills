## Distilled Rules

- Design is evaluated by communication and user fit, not only by personal expression.
- A design brief must name audience, message, context, constraints, and success criteria.
- Tools do not define design quality.
- A visual direction is only valid if it can be judged against Functionality, Efficiency, and Emotion.
