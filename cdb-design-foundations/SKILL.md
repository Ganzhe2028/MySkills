# CDB Design Foundations

Use this skill before visual execution when the task needs a clear design goal, design brief, or design-versus-art distinction.

## Core Position

In CDB, design is judged by whether it serves communication and other people under constraints. Art may center self-expression. A design can be expressive, but expression must serve the message, user, and situation.

## Workflow

1. Separate design delivery from art expression.
2. Define the audience: who needs to understand or act?
3. Define the message: what should they know first?
4. Define the context: where, when, and on what medium will this be seen?
5. Define constraints: size, tool, output, time, language, brand, or classroom requirement.
6. Set F.E.E. targets:
   - Functionality: what must work?
   - Efficiency: what must become easier?
   - Emotion: what should it feel like?

## Output Format

```markdown
## Design Brief
- Audience:
- Message:
- Context:
- Constraints:
- Success criteria:

## F.E.E. Targets
- Functionality:
- Efficiency:
- Emotion:

## Design vs Art Boundary
- Must serve:
- Can express:
- Avoid:
```

## Checks

- Do not start with style before clarifying audience and message.
- If the task is really self-expression, say so and explain how that changes evaluation.
- If the user asks for a visual direction, give only directions that can be evaluated against the brief.
- Keep the brief short enough to guide making, not become a document exercise.
