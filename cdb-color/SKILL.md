# CDB Color

Use this skill to make color decisions purposeful instead of decorative.

## Core Position

Color should do a job: create hierarchy, classify information, express state, support brand, set emotion, or prepare for output. More color is not better unless each color has a role.

## Workflow

1. Define the color job:
   - hierarchy
   - category
   - state
   - brand
   - emotion
   - output
2. Identify the output medium:
   - screen: RGB / Hex / HSB thinking is usually relevant
   - print: CMYK and print proofing concerns matter
3. Reduce palette roles:
   - main color
   - support color
   - accent color
   - neutral
   - semantic colors
4. Check contrast for text and key UI elements.
5. Check that the same color means the same thing everywhere.
6. Give a compact palette or correction plan.

## Checks

- Do not add color without assigning meaning.
- Do not rely on color alone for critical information.
- Do not ignore text contrast.
- Do not mix screen and print assumptions.
- Avoid chaotic palettes where every element competes for attention.
