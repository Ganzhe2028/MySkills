## Distilled Rules

- Color must have a job: hierarchy, category, state, brand, emotion, or output.
- RGB and Hex are useful for screen color; CMYK matters for print.
- HSB supports controlled color adjustment through hue, saturation, and brightness.
- Contrast is a layout and readability tool, not only a color property.
- Palette control means fewer roles used more consistently.
